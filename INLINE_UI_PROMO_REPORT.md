# Inline UI + Promo Update Report

## Что изменено

- Постоянная reply-клавиатура заменена на inline-навигацию под сообщениями.
- При `/start` бот пытается удалить старую reply-клавиатуру у пользователей прошлой версии.
- Все основные функции теперь видны без чтения `/help`.
- Добавлена кнопка `🎟 Активировать промокод` в главное меню.
- `🆘 Поддержка` открывает Telegram-аккаунт из `SUPPORT_USERNAME`.
- `⚙️ Админ-панель` по-прежнему доступна только ID из `ADMIN_TELEGRAM_IDS`.
- Админ-панель разделена на основной экран и `⚙️ Доп. настройки`.
- Telegram Stars сохранены и явно представлены кнопками тарифов при включённом провайдере и `price_stars > 0`.
- Добавлен пошаговый мастер промокода на подписку по логике присланного VPN-бота.
- Добавлены правила `Для всех / Только первая / Не первая`.
- Поддержаны `-1 = безлимитно` для общего количества активаций в UI и лимита на пользователя.
- Карточка промокода показывает текущее количество активаций и позволяет редактировать основные параметры.
- Промокод на подписку сразу выдаёт/продлевает доступ и помечается consumed.
- Скидочные промокоды к покупке сохранены как отдельный тип.
