# Telegram-native admin panel

Основное управление сервисом выполняется прямо из Telegram.

## Доступ

`ADMIN_TELEGRAM_IDS` в `.env` — единственный источник прав Telegram-администратора:

```dotenv
ADMIN_TELEGRAM_IDS=123456789
WEB_ADMIN_ENABLED=false
SUPPORT_USERNAME=your_support_account
```

Несколько администраторов указываются через запятую. Кнопка `⚙️ Админ-панель` показывается только разрешённым ID, но это не единственная защита: `/admin` и каждый `adm:*` callback повторно проверяют Telegram ID отправителя.

## Главное меню пользователя

Главное меню теперь полностью inline — кнопки находятся непосредственно под сообщением, как в типичном Telegram-сервисе:

```text
💬 Новый диалог       👤 Профиль
👑 Подписка           🎁 Пригласить друга
🎟 Активировать промокод
🆘 Поддержка          ❓ Помощь
📄 Условия использования
⚙️ Админ-панель       ← только ADMIN_TELEGRAM_IDS
```

`🆘 Поддержка` открывает `https://t.me/<SUPPORT_USERNAME>` из `.env`.

## Telegram Stars

Оплата Telegram Stars уже встроена. В разделе подписки кнопки Stars появляются, когда одновременно выполнены условия:

- провайдер `telegram_stars` включён;
- у тарифа задан `price_stars > 0`.

Invoice обрабатывается через `pre_checkout_query` и `successful_payment`, повторное событие не продлевает подписку второй раз.

## Админ-панель

Главный экран сделан компактнее:

```text
📊 Статистика
👥 Пользователи       💳 Платежи
📣 Рассылка           🎟 Промокоды
👑 Тарифы             🔌 Платёжные системы
🎁 Реф. система       🔔 Уведомления
🤖 AI                 ⚙️ Доп. настройки
🏠 Главное меню
```

`⚙️ Доп. настройки` содержит Trial, настройки сервиса, ошибки и AuditLog.

## Промокоды на подписку

`🎟 Промокоды → ➕ Промокод на подписку` запускает пошаговый мастер.

Настройки близки к присланному VPN-боту:

1. название промокода;
2. сам код;
3. тип подписки:
   - `Для всех`;
   - `Только первая`;
   - `Не первая`;
4. тариф, который выдаётся;
5. длительность в днях;
6. общее количество активаций (`-1` = безлимитно);
7. сколько раз один пользователь может активировать (`-1` = безлимитно).

Карточка показывает и `Текущих активаций`.

Промокод этого типа выдаёт подписку сразу после ввода пользователем, без обязательной покупки. Количество запросов и внутренние token-limits рассчитываются пропорционально длительности выбранного тарифа.

`Только первая` означает, что у пользователя раньше не было ни одной записи Subscription. `Не первая` — что подписка уже была хотя бы один раз. Trial в это условие не входит.

Старые скидочные промокоды сохранены отдельной кнопкой `💸 Скидка / бонус к покупке`; они продолжают применяться к следующему checkout.

## Миграция

Новая миграция:

```text
20260819_0011_inline_promo_ui.py
```

Она добавляет к `promo_codes`:

```text
name
grant_on_activation
subscription_scope
```

и разрешает `per_user_limit=-1` для безлимитного использования одним пользователем.

## Browser admin

Старая FastAPI/Jinja админка остаётся опциональной:

```dotenv
WEB_ADMIN_ENABLED=false
```

FastAPI/Nginx при этом всё равно нужны для health-check и внешних payment webhook/checkout маршрутов.
